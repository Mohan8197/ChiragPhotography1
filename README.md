# Chirag Photography

The original photography portfolio template has been customised for Chirag Photography while retaining its Next.js layout, gallery filtering, project pages, animations, transitions, lightbox, mobile navigation and visual styling.

## Run locally
Requirements: Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build
```bash
npm run build
npm start
```

## Deployment
This is a Next.js application, not a plain static HTML site. Deploy the repository to Vercel (recommended) by importing it from GitHub. Do not use GitHub Pages' simple branch publishing for this project; it does not run the Next.js server features and routes automatically.
